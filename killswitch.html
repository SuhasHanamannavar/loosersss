Post-revocation containment checklist

incident runbook
  1. 01Disable the identity with the wizard above; verify the actor appears in the disabled registry with a proof id.
  2. 02Revoke actor API keys issued under that identity on the integrations page; boot-time guards call process.exit(1) before any .env variable touches memory.
  3. 03Rotate shared credentials the actor could have copied (database password, Stripe restricted key, webhook secret).
  4. 04Watch the access log for blocked attempts; every later request from a revoked actor renders DENY at the verification boundary.
  5. 05Export audit evidence (JSON / CSV) from the logs page for the incident record and SOC 2 / ISO 27001 pack.
