How an envelope is sealed

zero secret residue
  1. 01Setup generates the ML-KEM-768 keypair (1184 B public key) for the organization. The private key never leaves the control plane.
  2. 02A protected read encapsulates a fresh 32-byte shared secret with the public key → 1088 B ciphertext; payload encrypts under AES-256-GCM with an HMAC-SHA-256 proof.
  3. 03The session key lives only in volatile memory for the duration of the system call and is scrubbed after plaintext consumption.
  4. 04After revoke, the decapsulation key material is locked behind non-invertible state; disk and memory inspection yields only ciphertext.
