Drop-in guard SDK

silica_guard.py · checkmate-guard.js
silica_guard.py · inserted at app startup 
# silica_guard.py — boot-time identity guard
from silica_guard import Guard

guard = Guard(endpoint="https://checkmate-guard.vercel.app/api/sync")

@app.before_request
def verify_identity():
    decision = guard.verify(actor=current_identity, asset="")
    # DENY before any .env variable or connection string touches memory
    if decision.status != "ok":
        raise SystemExit(1)
checkmate-guard.js · imported in server.js 
// checkmate-guard.js — verify before secrets load
const { Guard } = require("./checkmate-guard");

const guard = new Guard({
  endpoint: "https://checkmate-guard.vercel.app/api/sync"
});

app.use(async (req, res, next) => {
  const decision = await guard.verify({
    actor: req.user, asset: ""
  });
  // revoked identity → terminate before secrets reach process memory
  if (decision.decision !== "ALLOW") process.exit(1);
  next();
});

Adapter contract v1 · CLI

track4_service.py
operations · setup / read / revoke / protected_read / audit
# initialize durable state and asset registry
$ python track4_service.py --op setup --identity 

# owner-only standard read
$ python track4_service.py --op read --actor  --asset 

# commit revocation to the disabled registry
$ python track4_service.py --op revoke --actor 

# PQ-sealed read: KEM ciphertext + HMAC proof
$ python track4_service.py --op protected_read --actor  --asset 

# resolve a request_id to evidence
$ python track4_service.py --op audit
