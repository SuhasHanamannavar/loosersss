Containment scenarios covered

threat model · A / B / C
Scenario A · contractor exit

Freelancer keeps keys after Friday.

A contract finishes but the codebase, .env credentials and Stripe customer keys remain on a personal laptop. Password cuts do not touch files already downloaded.

revoke actor at the root · disabled before the next protected_read; the local envelope yields no plaintext.
Scenario B · stolen laptop

Device goes offline in airplane mode.

The laptop is lost in a cab. The attacker opens the lid and disables Wi-Fi; remote MDM wipe commands can never reach the machine.

offline device fails closed · ciphertext stays unrecoverable garbage without the ephemeral shared secret.
Scenario C · insider at exit

Disgruntled employee copies files.

An employee being fired tries to export confidential files before leaving. The old model trusts the token until it expires.

revoke commits atomic state · every later read DENYs before any key material is calculated.
